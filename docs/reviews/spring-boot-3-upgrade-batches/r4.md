## 問題清單

### [R1-1] `mall-tiny-02` 的 MBG 產碼器因移除 MySQL driver 已無法執行，文件沒有說明

- 嚴重度：low
- 位置：`CODEBASE_MAP.md:261`；`mall-tiny-02/src/main/resources/generator.properties:1`
- 問題：`generator.properties` 仍是 `jdbc.driverClass=com.mysql.cj.jdbc.Driver`，`generatorConfig.xml:47` 仍是 `sqlStatement="MySql"`。但 POM 已移除 MySQL driver，現在在本模組執行產碼器會在載入 driver 時拋出 ClassNotFound。就算接回 MySQL driver 重新產碼，產出的 mapper 也會把 `LAST_INSERT_ID()` 加回來，破壞 AC-17。CODEBASE_MAP 只寫「仍是舊 MySQL 產碼設定，尚未遷移」，讀者會以為產碼器還能照舊使用。
- 建議修法：在 `CODEBASE_MAP.md:261` 補一句：本模組 classpath 已沒有 MySQL driver，產碼器目前無法直接執行；若重新產碼，會覆蓋 `PmsBrandMapper.xml` 的 `useGeneratedKeys` 調整。

### [R1-2] §8.1 設定表的 `spring.datasource.*` 列仍寫一律 MySQL

- 嚴重度：low
- 位置：`CODEBASE_MAP.md:291`
- 問題：表格寫「MySQL 的 `mall_tiny` 資料庫」，和 `mall-tiny-02` 已改用 PostgreSQL 的現況不一致。下方 `:301` 段落有更正，但表格本身仍會誤導讀者。
- 建議修法：改成「MySQL 的 `mall_tiny` 資料庫（`mall-tiny-02` 為 PostgreSQL，見下方說明）」。

### [R1-3] 增量更新說明寫的是「未提交修改」，內容已過時

- 嚴重度：low
- 位置：`CODEBASE_MAP.md:280`

- 建議修法：改寫為「以 `spring-boot-3-upgrade` 分支的變更核對」，或註明 commit。
